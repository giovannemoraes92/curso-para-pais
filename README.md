# Como ajudar seu filho no futebol sem atrapalhar

Landing page do curso para pais de jovens jogadores, de Giovanne Moraes.

## Estrutura

- `index.html` — página principal
- `css/styles.css` — estilos
- `js/script.js` — interações
- `assets/` — imagens e materiais
